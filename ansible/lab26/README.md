# Lab 26: Structured Configuration Management with Ansible Roles

## 1) Lab Overview & Objectives

The Lab 25 playbook is split into three reusable roles (`docker`, `kubectl`, `jenkins`)
and one playbook that runs them.

## 2) Structure (`ansible/lab26/`)

```
lab26/
├── inventory
├── roles_playbook.yaml
└── roles/
    ├── docker/
    ├── kubectl/
    └── jenkins/
```

Roles can be scaffolded with `ansible-galaxy init docker`, etc.

## 3) Execution

```bash
ansible-playbook -i inventory roles_playbook.yaml --syntax-check
ansible-playbook -i inventory roles_playbook.yaml
```
